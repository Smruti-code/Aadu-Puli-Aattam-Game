# Aadu Puli Aattam – Goats and Tigers Game

# Aadu Puli Aattam-2.0

This is the extended version of the original Aadu-Puli-Aatam where there is Tiger AI playing along the Human goat.

## Version 2.0

Version 2 introduces a Human vs Tiger Strategist gameplay mode.

### Version 2 Features

- Human player controls the goats
- Tiger Strategist controls all three tigers
- Strategic tiger movement
- Automatic tiger capture decisions
- Goat placement and movement
- Legal move highlighting
- Tiger capture system
- Tiger victory after capturing 5 goats
- Goat victory when all tigers are blocked
- How to Play instructions
- Restart and Play Again options
- Improved game status panel
- Piece movement animation
- Improved Tiger AI decision-making

### Requirements

To run the project, install the Godot Engine on your computer.

- Godot Engine 4.x

## How to Install Godot
- Visit the official Godot Engine website.
- Download Godot Engine 4.x for your operating system.


## How to Run

1. Install Godot Engine.
2. Download or clone this repository.
3. Open the project in Godot.
4. Open `project.godot`.
5. Run the project.
